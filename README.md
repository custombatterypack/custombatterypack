# custombatterypack
Electrino EV 3D Custom Battery Designer एक आसान online tool है, जिसकी मदद से आप अपनी जरूरत के अनुसार custom lithium और LFP battery pack का 3D design तैयार कर सकते हैं। Battery cells, series-parallel configuration, pack size और battery layout को visualize करके electric scooter, e-rickshaw और अन्य EV applications के लिए battery planning करें।
